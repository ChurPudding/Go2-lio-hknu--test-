| | 현재 | 확정값 |
|---|---|---|
| hdop 가중 (227행) | `sg = gps_sigma * hdop_i / hdop_median` | 제거 |
| Huber (268행) | 1.345 | 1.5 (= 7.5 m / 5.0 m) |
| σ | 5.0 | 5.0 (일치) |

원하면 1.5 를 넣어야 합니다. 실시간 코드로 옮기기 전에 고치는 편이 좋습니다.

**`/hknu/robot_map` 은 이름만 잡아두고 비어 있습니다.** `pcd_to_grid.py` 출력을
여기 실으면 됩니다.
